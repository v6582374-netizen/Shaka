# 证据边界与真机迁移

## 当前公开接口证明什么

- 外部应用能够稳定调用；
- 请求校验、五态结果、动作计划、逐阶段轨迹和证据摘要具备完整形式；
- 正常、遮挡、保护拒绝和初始位姿变化分支可复现；
- 客户端不需要安装机器人 SDK 或拥有 G1。
- Qwen3-Max 的两次真实百炼调用、上下文、结构化计划、Request ID 和 token 用量已脱敏留存。
- manifest 绑定全部 JSON 工件；只读验证器会重放两轮结果并核对反馈映射、三种反馈策略和凭证边界。

## 当前公开接口不证明什么

- 未证明黄色按钮任务已在真实 G1 上成功；
- 仿真指标不能替代接触动力学、相机噪声或真机保护证据；
- 当前定位置信度、接触误差和间隙是构造型契约夹具，不是图像、传感器或物理引擎测量；
- `succeeded` 只在 `evidence_level=illustrative_simulation` 的范围内成立。
- 固定基座条件下的软件指标改善不能外推为机器人定位、接触或动力学性能。

## 接入真机时保持不变的部分

请求契约、单次尝试语义、五态输出、独立评估、证据摘要和客户端调用方式全部保持不变。

## 真机适配器需要补充的部分

1. 受批准的现场身份与短时授权；
2. 真实相机、机器人状态和唯一控制入口；
3. 机器人侧硬件保护证明；
4. 不可变原始视频和遥测清单；
5. 独立评估与人工最终审校。

这种分层让主办方今天可以评测完整软件接口，未来拥有硬件时也不需要重新集成。
