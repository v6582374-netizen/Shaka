The closed loop

不是一次生成，
而是持续修订

Shaka 将开放式智能约束在一条可审计闭环中。Qwen 可以提出计划，但不能改写目标、保护边界与评价标准；执行结果由模型之外的程序判定，再作为证据进入下一轮。

01 / INTENT

冻结科学问题

先定义任务成功、保护边界与证伪条件，避免系统在运行中偷换问题。

02 / PLAN

Qwen 形成计划

把目标转化为结构化、受约束、可执行且可比较的实验方案。

03 / REHEARSE

数字预演

在写入机器人之前检查动作空间、参数边界和显而易见的危险。

04 / ACT

进入 G1 真机

接入真实相机、机器人状态与控制通道，在监督下进行物理金丝雀。

05 / JUDGE

独立评价与拒绝

安全门和评价器不服从模型意愿；安全拒绝也是有效证据。

06 / EVOLVE

失败归因与进化

保存差异、回执与原始工件，让下一轮改变有来源、有边界、可回放。

What worked

链路、监督与记录

运行记录摘要与历史执行代码支持控制进入和安全中止事实；公开仓库尚不包含完整原始遥测、视频和执行回执。

What did not

动态适配与任务效果

静态边界合格不等于真实运动可靠。当前策略缺少对实时力矩与接触状态的闭环适配，尚未形成稳定任务成功。

Qwen feedback cycle

证据如何改变
下一轮方案

赛事代表案例用确定性软件工件证明“反馈能够改变计划”，真机金丝雀则证明这条闭环可以延伸到物理世界。两类证据各自回答不同问题，不互相冒充。

Round 01 · baseline

先建立可证伪的基线

  • 冻结目标、预算与安全边界
  • 运行标准任务并保留原始轨迹
  • 由独立评价器指出失败项
→
Round 02 · evidence-guided

只修改证据支持的部分

  • 保留未被证伪的目标和约束
  • 针对失败原因调整控制量
  • 在同一口径下再次验证改动
Research frontier

从能拒绝，
走向会适应

Shaka 当前最有价值的结论不是“机器人已经学会”，而是把未来科研必须跨越的边界暴露出来：安全、适应与进化不能靠一次离线生成同时解决。

实时反馈控制

把力矩、接触与视觉变化真正纳入动作修正，使策略不再只满足执行前的静态检查。

跨场景经验积累

从单次失败归因走向可迁移的技能与世界模型，检验改进是否超越某一个确定性案例。

受约束的长期自治

让开放式规划保持创造力，同时保证目标、授权、安全门和证据身份始终不可被模型自行改写。

真正的具身智能，不只是在世界中行动；它还应理解行动留下的证据，并据此成为下一轮更可靠的自己。
