# 用隔离的提交适配器提供公开测试 API

ADR-0001 为抵达首次真机可信成功而拒绝预建 HTTP 推理平台。赛题新增了不同目标：评委在不具备 Unitree G1 的情况下，仍需调用应用并观察完整输入、过程与输出。因此，公开测试入口不能依赖机器人、MuJoCo、内部 Coworker 后端或常驻数据库。

## 决定

增加一个隔离的、无状态的提交适配器。它用稳定 HTTP/OpenAPI 契约表达同一个单次调用生命周期，默认执行确定性契约仿真，并在每个结果中声明 `physical_execution=false` 与 `writes_to_robot=0`。真机接入未来只作为同一契约下的受批准执行模式，不改变评委调用方式，也不授予任何硬件写权限。

提交适配器只承担四项职责：契约校验、形式化生命周期演示、结构化输出、公开文档与交互页面。它不承担策略训练、经验存储、工作流调度、真机控制或物理效果证明。

## 与既有决定的关系

ADR-0001 对内部物理研究闭环继续有效；本决定不是把内部系统服务化，而是在系统边缘增加比赛交付适配器。两者的边界由结果中的证据等级与物理执行声明强制区分。
