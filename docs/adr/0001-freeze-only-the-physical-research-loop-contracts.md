# 只冻结真机研究闭环的跨候选契约

首版的目标是以最低必要复杂度取得黄色按钮任务的首次可信成功，而不是预先建设通用机器人学习平台。因此，除候选实现格式、调用证据记录格式和唯一机器人控制入口外，只再冻结四个跨候选契约；首版全部通过版本化文件和本地 CLI 交换，不部署服务。

## 决定

1. **任务调用契约**：调用只表达黄色按钮任务意图；一次调用只包含一次尝试；标准机械臂与灵巧手起始状态、最长执行时间和 `succeeded | failed | indeterminate | aborted | abstained` 语义固定。
2. **候选准入契约**：任何行为克隆、强化学习、启发式、代码策略或混合候选，在获得真机写权限前必须提交完整候选包，并依次通过静态检查、历史回合离线回放和读取真实观测但不发布命令的端到端运行。
3. **评估契约**：独立评估器只读取完整调用证据，输出结构化视觉事实、五态任务结果、评估器版本和输入摘要；候选不能访问或改写评估器，人工审校独立保存且不成为当前回合训练反馈。
4. **复位与就绪契约**：`failed` 或 `indeterminate` 后，候选之外的固定程序通过唯一控制入口恢复标准起始状态，并在机器人状态、相机、记录器和控制权检查通过后才允许创建下一次调用；`aborted` 后停止自主循环，不自动继续。

每次自主研究另有一个版本化运行清单，绑定总真机回合预算、机器人运行时间预算、冻结契约摘要、当前候选、回退候选和全局停止原因。它是配置工件，不是新服务。

## 明确不建设

- 不建设 HTTP 推理服务、消息总线、Redis、数据库、工作流平台或常驻调度服务。
- 不预先统一感知、三维恢复、规划、逆运动学、动作原语、VLA、行为克隆或强化学习的内部接口；它们都是候选内部实现。
- 不建设通用模型注册表、向量经验库、跨技能技能库、世界模型旁路、仪表盘或多智能体角色系统。
- 不依赖人工预采集的开发集或验收集；评估器使用自然运行产生的证据，人工只审校结果。
- 不在首次可信成功之前实施技能安装、可靠性晋级、泛化验证或第二技能复用机制。

只有第二个独立技能暴露出至少两处真实重复，或当前单技能闭环出现无法由候选内部修改解决的具体瓶颈，才允许提取新的通用接口。设想中的未来复用不构成抽象依据。
